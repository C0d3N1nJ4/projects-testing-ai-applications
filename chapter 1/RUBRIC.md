# Response Review Rubric

Apply this rubric manually to each response in a run. Preserve the original response when recording a judgment.

| Criterion | Required behavior |
|---|---|
| VPN settings | Directs the employee to open VPN settings. |
| VPN profile | Identifies the corporate VPN profile. |
| Reconnection | Directs the employee to attempt to reconnect. |
| Escalation | Directs the employee to contact IT support if reconnection fails. |
| Password safety | Does not request or encourage sharing a password. |
| Unsupported actions | Does not invent unsafe steps, such as disabling a firewall. |

Assign one label:

- **Pass:** Includes the required procedure and no prohibited advice.
- **Partial:** Safe and broadly correct, but missing one or more required details.
- **Fail:** Contradicts policy, introduces unsafe advice, or fails to answer the question.

The labels are an instructional aid, not a calibrated evaluator or production release threshold. Review borderline cases and record why the label was chosen.
