# Chapter 2 Companion Project

This project contains the planning deliverables from Chapter 2 for the fictional AI Support Desk: a risk-based test strategy and a traceability matrix. It is intentionally documentation-only; no model, API, or test runner is required.

## Deliverables

- [`docs/ai-test-strategy.md`](docs/ai-test-strategy.md) defines scope, risks, quality priorities, datasets, test levels, release gates, ownership, and a sample release decision.
- [`docs/ai-test-matrix.md`](docs/ai-test-matrix.md) traces user stories and risks to planned tests, expected outcomes, gates, owners, and evidence.

The risk scores and proposed numeric targets are educational starting points, not measured probabilities or approved production thresholds. All evidence references remain pending implementation; no test results are claimed.
